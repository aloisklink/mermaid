# @mermaid-js/diagram-sequence

The sequence diagram for mermaid. `mermaid` bundles and registers it, so you don't need to install this package yourself.

It is mermaid-v13's sequence diagram, ported from [mermaid-v13](https://github.com/mermaid-js/mermaid-v13/tree/87edaac12eb324c461caf6b923f4d50390dcf9b3/packages/diagram-sequence) as a `DiagramDefinitionV13` (see `@mermaid-js/core/v13`).
